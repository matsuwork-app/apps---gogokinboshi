# 試合間のチーム再編成と日次得点表示 実装計画

## Goal

- 2〜4チームのイベントで、試合と試合の間に参加者の所属チームを変更できる。
- 変更後に作成する試合は新しい所属を使い、作成済み試合のラインナップと結果は変えない。
- 各参加者のイベント当日の累計得点を、イベント詳細・次試合作成・試合記録・チーム編成の各画面で常に確認できる。

## Spec

- チーム再編成は管理パスコード認証済みの操作だけ許可する。
- `pending` / `active` / `paused` の試合が存在する場合は再編成を拒否し、試合終了後に行うよう案内する。
- イベント参加者を重複・欠落なく、イベント内の既存チームへ1回ずつ割り当てる。各チームは1名以上とする。
- `event_team_members` の更新はDB関数内の単一トランザクションで行う。
- `match_lineups` は変更しない。`create_match_with_teams` が次回作成時に最新の `event_team_members` をコピーする既存仕様を利用する。
- 日次得点は `goals` をイベント単位で集計し、`member_id` ごとに表示する。試合画面で得点を増減した際は当日累計も楽観更新する。
- 表示文言は小さな薄い文字の `本日 N点` とする。

## Constraints

- 新規DB関数: `public.reassign_event_team_members(p_event_id uuid, p_assignments jsonb) returns void`。
- DB関数の実行権限は `service_role` のみに付与し、公開ロールからは剥奪する。
- Server Action は `requireManagerSession()` を必ず実行し、入力を検証してから管理用SupabaseクライアントでRPCを呼ぶ。
- Next.js 16のServer Action / Server Component規約に従う。
- `.claude/worktrees/` は既存の未追跡データとして触らない。
- 完了前にVitest、型検査、ビルド、Supabaseマイグレーション検証、Playwright主要フローを実施する。

## Tasks

1. DB契約と回帰検証
   - `supabase/migrations/202609280001_reassign_event_team_members.sql` を追加する。
   - イベント・チーム・参加者の整合性、全員一意、全チーム1名以上、未終了試合なしをDB側で検証する。
   - `scripts/verify-supabase-migrations.mjs` に成功・拒否・過去ラインナップ不変の検証を追加する。
   - `src/types/database.ts` に新RPC型を追加し、生成型との一致をCIで確認する。

2. 管理操作とチーム編成UI
   - `src/app/actions/events.ts` に再編成Actionと入力検証を追加する。
   - `src/app/events/[id]/teams/edit/page.tsx` とClient Formを追加する。
   - 全参加者の所属選択、チーム人数、保存、認証ダイアログ、エラー表示を実装する。
   - イベント詳細に現在所属と編成変更導線を表示する。

3. 日次得点の全フロー表示
   - イベント詳細のチーム別参加者に `本日 N点` を表示する。
   - 次試合作成画面の各参加者に `本日 N点` を表示する。
   - 試合画面の各選手に `本日 N点` を表示し、得点追加・取消時に現在試合得点と日次得点を一緒に楽観更新・ロールバックする。
   - チーム編成画面でも同じ集計値を表示する。

4. 統合検証と公開
   - Action/ComponentのVitestを追加・更新する。
   - Playwrightで、3チームイベント作成→第1試合終了→所属変更→第2試合作成→過去ラインナップ不変・新所属反映・日次得点継続表示を確認する。
   - Preview Supabaseへマイグレーション適用後、Previewデプロイを検証する。
   - 独立レビューでDB権限・競合・UI回帰を確認し、指摘を解消する。
   - Production DBへマイグレーションを適用してからアプリを公開し、非破壊の本番スモークテストを行う。

## Acceptance Criteria

- 終了済み試合のラインナップは、後からチーム編成を変えても変化しない。
- 再編成後に作成した試合には新しい所属が使われる。
- 未終了試合がある場合は再編成できない。
- 参加者の当日累計得点が4つのイベント関連画面すべてで確認できる。
- 試合画面で得点を追加・取消すると `本日 N点` が即時に増減し、保存失敗時は元に戻る。
- 公開閲覧は従来通り維持され、再編成の保存だけが管理認証で保護される。
